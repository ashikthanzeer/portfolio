## Requirements
### Requirement: Technical Skills Grid Classification
The portfolio SHALL display a categorized technical skills section grouped into:
- Languages: Python, C, JavaScript
- Web Technologies: HTML, CSS
- Databases: MySQL
- Tools: Git, GitHub, Linux
- Core Concepts: Data Structures, Object-Oriented Programming, Problem Solving

#### Scenario: Displaying Skills
- **WHEN** the user views the skills section
- **THEN** all categories and their respective skills MUST be displayed.

### Requirement: Interactive Hover feedback
The skills displays SHALL have visual feedback (e.g. glowing border, color shift, or code syntax styling) when the cursor hovers over individual items or categories.

#### Scenario: Hovering on Skills
- **WHEN** the user hovers over a skill item or badge
- **THEN** a glowing accent highlight MUST be applied.
