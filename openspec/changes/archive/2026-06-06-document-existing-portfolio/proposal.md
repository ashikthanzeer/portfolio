## Why

The portfolio project has been built without formal specifications or documentation. Establishing OpenSpec documents for the existing code will create a clear reference for future feature enhancements, design iterations, and automated testing.

## What Changes

This change introduces comprehensive OpenSpec documents mapping the existing portfolio codebase. No functional changes or visual updates will be made to the actual application code. Specifically, this change will:
- Establish a baseline proposal outlining the current capabilities.
- Define specifications for the core landing page layout and interactive education detail popups.
- Document the design architecture and styling principles used.

## Capabilities

### New Capabilities

- `portfolio-home`: Main landing page interface including headers, personal descriptions, and social media icons.
- `education-details`: Interactive modal dialogs detailing education timelines and academic performance (CGPA) that trigger when clicking on education cards.

### Modified Capabilities

<!-- None -->

## Impact

This is a documentation-only change. It does not affect any application APIs, runtime dependencies, or external systems, but establishes the specification structure under the `openspec/` directory.
