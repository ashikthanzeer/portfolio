## Why

To enhance the visual premium look of the portfolio page, the user has provided an abstract blue/black paint texture image. Setting this image as a rotated background texture will provide a highly immersive, deep cosmic/high-tech atmosphere to the website.

## What Changes

This change:
- Copies the user-selected background image into the portfolio project directory.
- Updates the background styling in `styles.css` to render this image as a fixed, rotated texture layer behind all page content.
- Applies standard CSS blending and opacity filters to ensure body text remains perfectly legible.
