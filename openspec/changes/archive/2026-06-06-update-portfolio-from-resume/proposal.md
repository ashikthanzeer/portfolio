## Why

The portfolio needs to be updated to match the user's current resume, showcasing their latest projects, education, and technical skills. Upgrading the theme to a high-tech/cyberpunk aesthetic will better reflect their Computer Science background, creating a memorable and professional impression.

## What Changes

This change overhauls the design and structure of the portfolio site using HTML, Vanilla CSS, and JavaScript:
- **Visual Redesign**: Implements a high-tech, futuristic dark theme with neon cyan/amber accents, glowing interactive elements, terminal-style text effects, and glassmorphic layouts.
- **Resume Link**: Adds a prominent "View Resume" button at the top header that opens a new tab displaying a beautifully structured, printable HTML resume page (`resume.html`).
- **Projects Showcase**: Adds a responsive cards section showcasing StudyPlanner, ScoreFusion, and Expense Tracker with placeholder links for source code and live demos.
- **Education Update**: Adds Al Huda English School Neerkunnam as a third card in the education grid with detail popups showing board results and entrance exam ranks (JEE, KEAM, CUSAT).
- **Technical Skills Section**: Introduces a dedicated skills block grouping languages, databases, tools, and core CS concepts with interactive hover indicators.
- **Responsive Layout**: Optimizes the entire grid structure for seamless experience across mobile, tablet, and desktop viewports.

## Capabilities

### New Capabilities

- `projects-showcase`: A section displaying projects with tech badges, description list points, and mock links to GitHub/Live builds.
- `resume-viewer`: A standalone, beautifully styled `resume.html` page mimicking a clean professional PDF layout with printable styles.
- `technical-skills`: A skills category layout highlighting languages, databases, web technologies, tools, and core CS concepts.

### Modified Capabilities

- `portfolio-home`: Overhauling the core layout, background styles, color schemes, animations, and typography to a "techy" theme, and adding header links.
- `education-details`: Adding Al Huda English School Neerkunnam card to the education list and defining its detailed popup behavior.

## Impact

Modifies `index.html`, `styles.css`, and `script.js` to support the new features, styling, and interactivity, and introduces `resume.html` as a new page.
